# SAN-V1 Arduino IDE Package

Start with `START_HERE_WINDOWS.md`.

Package contents:

- `01_ESP32_USB_TEST/` — proves Windows driver, COM port, upload, and serial.
- `SAN_V1_Arduino/` — Arduino IDE version of the SAN-V1 firmware.
- `BENCH_RUN_SHEET.md` — tomorrow's physical bench evidence sheet.
- `validate_csv.py` — checks the CSV structure and 10 Hz sampling rate.

The first upload is performed on a completely bare, USB-powered ESP32. This
package does not authorize connection to motorcycle power or signals.
