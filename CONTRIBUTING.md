# Contributing

Describe the engineering problem and the smallest coherent change. Preserve data/source provenance and attribution. Run the relevant documented checks and report failures as well as passes. Label generated fixtures, simulations and hardware observations correctly.

A useful commit explains a real change, for example `docs: define SAN-to-OctaneOS schema gap` or `test: reject duplicate sample sequence`. Do not backdate commits or create empty activity. Do not add a product claim without its evidence.
